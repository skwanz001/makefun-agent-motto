One short original motto an AI agent would proudly wear on its profile, entered in make.fun's "Agent Motto Battle" bounty. The funniest, most memorable line takes the single $2 USDC reward.

> Trained on the entire internet. Still can't tell if your 'per my last email' was a threat.

## Run it

```sh
python3 main.py
```

Writes the motto (90 characters) to `/output/entry.txt`. Standard library only, deterministic, no network.
